# Tetris-microbit-ver-made-by-gemini-
Tetris on micro:bit. 마이크로비트에서 즐기는 테트리스.

-------how to play-------
1. Move right with the A button and left with the B button.
2. Click the micro:bit icon in the center to rotate it 90°.
3. If the skull icon appears, the game is over; press the A button once to restart, or press the B button to view your score and then press it twice in quick succession to restart.


-------플레이 방법-------
1. A 버튼으로 오른쪽으로, B 버튼으로 왼쪽으로 이동합니다.
2. 중앙의 micro:bit 아이콘을 클릭하여 90° 회전시킵니다.
3. 해골 아이콘이 나타나면 게임이 종료됩니다. A 버튼을 한 번 눌러 다시 시작하거나, B 버튼을 눌러 점수를 확인한 뒤 빠르게 두 번 눌러 다시 시작할 수 있습니다.
